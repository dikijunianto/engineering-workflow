# DevQuest visual asset

`backgrounds/midnight-reach.png` is an original landscape generated for this UI
with the built-in image generation tool (generate mode, not CLI fallback).
It is stored locally; the application never hotlinks artwork. Replace the image
or change `--hero-art` in `public/style.css` to update the atmosphere.
The logo and role icons are code-native SVGs, not generated game assets.

## Final generation prompt

Use case: stylized-concept; Asset type: wide panoramic hero background for a local engineering dashboard, designed to be cropped to a 220px-high banner and masked with CSS; Primary request: an original midnight fantasy landscape with layered slate-blue mountains, pine forest silhouettes, a distant small fortress on a ridge in the right half, and a misty cyan valley; Scene/backdrop: expansive nocturnal mountain valley beneath a subtle star field; deep atmospheric depth; Style/medium: refined painterly atmospheric concept art, elegant and cinematic, realistic stylization; not pixel art, not cartoon; Composition/framing: wide banner composition, ideally 1536x768 or wider; left 45 percent mostly dark negative space suitable for UI text; central and right landscape clearly visible; fortress small and distant, never dominant; crop-safe for a shallow hero banner; Lighting/mood: restrained cool moonlit ambience, soft cyan mist, tiny warm fortress windows only; Color palette: deep navy #06101f at the edges, slate blue mountains, muted cyan haze, restrained warm amber pinpoints; Constraints: no text, no logos, no UI chrome, no characters, no watermark, fully original scene, no recognizable copyrighted game assets; Avoid: pixel art, cartoon rendering, bright saturated colors, busy left side, large castle, foreground characters, game interface elements.
