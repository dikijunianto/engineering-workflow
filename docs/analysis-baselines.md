# Analysis baselines

Fresh Analyze Repository Impact fetches the configured base branch from `origin` for each selected registered repository. It resolves the remote tracking ref to an exact commit, then creates or reuses a clean detached Git worktree under DevQuest's local `analysis-worktrees` directory. No checkout, pull, reset, merge or source edits are performed in the user's original repository. Fetch updates origin's local tracking ref; it does not force-update local master or a feature branch.

The Quest stores each selected repository ID, branch, remote, commit, snapshot path and fetch time in `analysisBaselines`. Architect and Planner analysis/TRD/spec/plan access grants use those snapshots with the existing read-only permissions. Prompt repository paths and backend Git metadata refer to the effective snapshots. Resume and stage retry reuse the pinned snapshot instead of fetching a different commit. A new explicit analysis refreshes the baseline; existing implementation worktrees block that refresh. Source artifacts and history are retained, while changed recorded baseline identities invalidate previous approval bases.

New implementation worktrees use the recorded analysis commit, in both workflow engines. Legacy Quests with no recorded baseline retain their existing branch-resolution policy. Existing worktrees and the current Refactor Modul PIN Quest were not rebased or migrated. This feature does not automatically unblock legacy tasks or fix source baseline compilation failures.

Failures before agent reasoning are actionable: failed fetch/authentication, missing configured branch, and a dirty or changed managed snapshot stop the operation. There is no fallback to a stale checkout after fetch failure. Partially prepared snapshots are retained and can be reused by exact commit; no destructive cleanup is introduced.

Validation uses temporary local repositories and fake AI runtimes: two selected repositories, a stale feature checkout with uncommitted work, exact remote file content, clean read-only snapshot grants, implementation commit pinning despite local ref changes, snapshot reuse/tampering rejection, fetch failure before any agent, and changed-baseline approval invalidation. No company Git fetch, paid AI call, Jira operation, commit or push was performed. The app was restarted after confirming no agents were running.
